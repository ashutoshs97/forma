# FORMA

A minimal editorial portfolio of twenty AI-generated model and product campaign concepts.

The separate **By product** page (`dist/products.html`) organizes 27 images by product and audience: Women, Men, and Unisex. It includes sarees, purses, crop tops, tops, bottoms, kurtas, beauty, eyewear, jewelry, footwear, fragrance, watches, audio, and home & drinkware. Categories describe the featured product; audiences describe campaign styling. Product filters can be combined with audience filters and shared through the page URL.

## Preview

Open `dist/index.html` in a browser. No installation or build step is required.

## Deploy to Netlify

Import this GitHub repository in Netlify. The included `netlify.toml` sets the publish directory to `dist`. Leave the build command empty.

## Customize

- Campaign titles, descriptions, categories, and image filenames: `dist/app.js`
- Page content: `dist/index.html`
- Styling: `dist/style.css`
- Product catalog content: `dist/products-data.js`
- Product catalog behavior and styling: `dist/products.js`, `dist/products.css`
- Campaign images: `dist/assets/`

The images are illustrative AI-generated concept work, not commissioned brand photography. Contact details are not configured. The project brief form downloads a text file locally; it does not send submissions.
